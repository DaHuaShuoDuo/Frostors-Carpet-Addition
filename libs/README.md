# Development dependencies

JAR files in this directory are ignored by Git and are not distributed with FCA.

Before building, download the Carpet release matching the target Minecraft version and
place it here with these exact names:

- `fabric-carpet-26.2.jar`
- `fabric-carpet-26.3.jar`

Carpet is a compile-only dependency. It is not bundled into the FCA artifact and must be
installed separately on the runtime server.
